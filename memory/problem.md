## Open Issues

1. **Upgrade Complex Fixes (Vastu & NBC) to Gemini 3.8**: 
   Use `gemini-3.8-flash`. When the user asks to "fix Vastu" or "ensure NBC compliance", the AI has to juggle multi-step logic (e.g., if kitchen is in NW, move it to SE, but make sure the bathrooms still fit in the left bay). The new Gemini 3.8 Flash model's deep context and reasoning capabilities will drastically reduce the chances of the Drafter failing due to a bad LLM topology.
   
2. **(Future) Rendering Realistic 3D Plans**:
   Use `gemini-3-pro-image` (Nano Banana Pro). Currently, we only render 2D layouts and standard 3D walls. In the future, you could take the 2D layout generated by the geometric drafter and pass it into this image generation model to create stunning, highly contextual 3D photorealistic renderings of the floor plan for your users.
